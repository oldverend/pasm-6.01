# PASM

**PASM** — ассемблер собственного дизайна, вдохновлённый такими популярными ассемблерами, как **NASM**, **FASM** и **MASM**.

Проект предназначен для написания программ на языке ассемблера и их последующей трансляции в машинный код.

⚠️ Проект находится в разработке. Синтаксис, инструкции и архитектура могут изменяться.

## Возможности

* Ассемблерный синтаксис в стиле NASM/FASM/MASM

* Перевод исходного кода в машинный код

* Поддержка меток и переходов

* Работа с регистрами и непосредственными значениями

* Комментарии в исходном коде

* Директивы ассемблера

* Расширяемая система инструкций

* Возможность создавать программы с минимальным уровнем абстракции

## Пример

org 1000h0



push 10h0



section .data

&#x20;   msg db 'Hello, World!' 1 \& 0



section .text

&#x20;   jmp start:



start:

&#x20;   mov AX, msg

&#x20;   mov AX, 10h0

&#x20;   end



post 10h0
Синтаксис PASM стремится оставаться простым и понятным для пользователей, знакомых с NASM, FASM или MASM.

## Использование

Базовый формат команды:

pasm.exe <имя файла.pasm> <имя файла компиляции.bin .img .iso .exe>
Например:

pasm hello.pasm -o hello.img
pasm hello.pasm -o hello.exe
И да расширения файла .pasm

Полученный файл можно использовать в дальнейшем в зависимости от выбранного формата выходных данных и целевой платформы.

## Цели проекта

Основные цели PASM:

* создать понятный и быстрый ассемблер;

* сделать архитектуру проекта расширяемой;

* поддерживать привычный для программистов ассемблерный синтаксис;

* упростить добавление новых инструкций и архитектур;

* предоставить удобный инструмент для изучения устройства ассемблеров и машинного кода.

## Совместимость

PASM **не является прямой заменой NASM, FASM или MASM** и не стремится к полной совместимости с их исходным кодом.

Сходство синтаксиса используется для того, чтобы разработчикам, знакомым с существующими ассемблерами, было проще начать работу с PASM.
